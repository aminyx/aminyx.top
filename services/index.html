Отдельно от основной работы беру проекты под ключ: от бота с оплатой до сервиса с сайтом, кабинетом и серверами. Код пишу вместе с AI-агентами, проверяю тестами и сдаю работающим.

Что делаю

  • Telegram-боты с оплатой

    Продажи, подписки, напоминания, админ-команды, приём оплаты через платёжного провайдера (СБП, карта, криптовалюта).

    Примеры: SomonVPN, VPN-сервис для клиента

  • Бэкенд и API

    Python (FastAPI) или Go, PostgreSQL, вебхуки платёжных систем, фоновые задачи.

    Примеры: SomonVPN

  • Сайты и личные кабинеты

    React / TypeScript или Next.js, вёрстка по макету, несколько языков.

    Примеры: VPN-сервис для клиента, aminyx.top

  • Android-приложения

    Kotlin, Jetpack Compose.

    Примеры: SomonVPN

  • Серверы и автоматизация

    Linux, Docker, мониторинг с оповещениями в Telegram, резервные копии, развёртывание с откатом.

    Примеры: SomonVPN

  • VPN-сервис под ключ

    Серверы, бот продаж, автоматическая выдача доступа, мониторинг.

    Примеры: VPN-сервис для клиента

Как работаю

1. Разговор
Обсуждаем задачу.
2. План
Присылаю план по этапам с ценой и сроком на каждый этап. Почасовой оплаты нет.
3. Работа
По ходу показываю демо и промежуточные сборки.
4. Сдача
Сдаю работающий продукт и исходный код.
5. Поддержка
Поддержка после запуска — по договорённости.
Сколько стоит?
После разговора присылаю план с фиксированной ценой по этапам.
Какие сроки?
Ставлю в том же плане. Пример: VPN-сервис с сайтом, ботом и серверами занял около двух недель.
Что я получу?
Работающий сервис, исходный код и инструкцию по запуску.
Будет ли проект в портфолио?
Только с вашего согласия. Без него — анонимно.
